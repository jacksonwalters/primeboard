Primeboard 1.3.2 brings the Linux desktop downloads up to date with the web app, including playable fullscreen visualizations and MIDI volume-knob support.

## What changed since 1.3.0

- Expand any visualization to fullscreen while continuing to play with your computer keyboard or MIDI controller, or while a song plays. Show keyboard brings back the touch keys; Escape or the exit button returns to the regular view without clearing notes.
- MIDI volume knobs (CC7), including the M-Audio Keystation Mini 32 MK3's default assignment, control Sound volume. The on-screen slider follows the knob, including during songs and fullscreen. Pitch mappings and visualization strengths stay the same.
- Updated How to use and The math explanations for fullscreen and MIDI volume.

ZIP bundles are also attached. Extract the entire ZIP before opening the app; the DEB installer is preferred because the package manager resolves system dependencies. Raspberry Pi requires a 64-bit desktop OS.

The app bundles its Electron runtime and works offline, with all five visualizations, the music library, recording and video export, and MIDI support. A separate browser, Node.js, and Python are not needed. Updates are installed manually; saved recordings and settings remain in the app profile.

## Validation

Both architectures pass all 163 application tests and build on native Linux runners. Each DEB is installed and removed in clean Debian 12/13 and Ubuntu 22.04/24.04 containers, checking runtime libraries, the application launcher, and sandbox permissions. Release preparation checks package integrity, architecture, version, and that bundled app source and data match the release commit.

These automated checks do not replace installed GUI, MIDI, and audio-latency testing on the intended Linux computer or Raspberry Pi.

`SHA256SUMS.txt` contains SHA-256 integrity hashes for every attached installer and ZIP.
